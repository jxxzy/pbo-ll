# Praktikum Bab 10 — CRUD dan Validasi Form

Aplikasi MVC menggunakan SQLite, ViewModel dengan DataAnnotations, serta operasi Create, Read, Update, dan Delete.

```powershell
dotnet run --project PraktikumBab10.csproj
```

Buka URL yang ditampilkan oleh `dotnet run`. Database lokal `gudang.db` dibuat otomatis.
