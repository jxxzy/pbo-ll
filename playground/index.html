Pengaturan runner lokal

Bab 1–7 dapat dijalankan langsung dengan compiler WebAssembly pada build GitHub Pages yang memiliki runtime. Input stdin dan perubahan csproj hanya didukung runner lokal. Bab 8–11 memerlukan ASP.NET Core di server. Untuk menjalankan semua project secara lokal, instal Node.js 22+, Git dan Docker Desktop (Linux containers), lalu jalankan:

git clone https://github.com/jxxzy/pbo-ll.git
cd pbo-ll
docker build -f runner/Dockerfile -t pbo2-lab:net10 .
npm run playground

Buka playground lokal · Gunakan hanya kode yang kamu percayai. Runner ini bukan layanan eksekusi publik.
