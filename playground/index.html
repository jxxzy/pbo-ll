Pengaturan runner lokal

Bab 1–7 dapat dijalankan langsung dengan compiler WebAssembly pada build GitHub Pages yang memiliki runtime. Input stdin didukung runner lokal; perubahan csproj harus dijalankan dengan dotnet di Codespaces atau PC (runner Docker memerlukan csproj asli). Bab 8–11 menyediakan lab browser dengan SQLite sungguhan, tetapi tidak menjalankan controller atau Razor C#. Untuk menjalankan project ASP.NET asli secara online, gunakan GitHub Codespaces. Untuk menjalankan semua project secara lokal, instal Node.js 22+, Git dan Docker Desktop (Linux containers), lalu jalankan:

git clone https://github.com/jxxzy/pbo-ll.git
cd pbo-ll
docker build -f runner/Dockerfile -t pbo2-lab:net10 .
npm run playground

Buka playground lokal · Gunakan hanya kode yang kamu percayai. Runner ini bukan layanan eksekusi publik.

Bab 8–11: dua mode berbeda

Lab Web menjalankan latihan MVC, CRUD dan API versi browser dengan SQLite nyata. Edit source C# tidak memengaruhi lab browser. Untuk compile dan menjalankan project asli dari browser, buka Codespaces (akun GitHub dan kuota diperlukan).

↗ Buka GitHub Codespaces

Di terminal Codespaces: bash scripts/run-cloud-lab.sh 8. Untuk semua server web sekaligus: bash scripts/start-cloud-studio.sh.

↗ Buka aplikasi ASP.NET asli di Codespaces
