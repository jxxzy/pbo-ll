HELP CENTER
Butuh bantuan?
Bagaimana menjalankan C# di browser?
Buka C# Studio, pilih Bab 1–7, lalu Run. Runtime Roslyn/WebAssembly dikemas di situs.
Bagaimana menjalankan ASP.NET asli?
Gunakan GitHub Codespaces dan bash scripts/run-cloud-lab.sh 11 (ganti nomor sesuai bab), lalu buka port private. Untuk IDE privat seluruh bab, gunakan launcher bash scripts/start-private-ide.sh setelah rebuild devcontainer.
Apakah data tersinkron antar perangkat?
Tidak. Gunakan backup dan restore Study Tools untuk memindahkan progres lokal.
Pintasan keyboard
/ mencari materi, Ctrl+Enter menjalankan kode melalui editor Monaco. Gunakan tombol tema di header.
